# 华医网考试助手

面向华医网继续医学教育课程页面的浏览器用户脚本，提供待考课程管理、结果记录与连续考试辅助。

## 功能

- 扫描项目中的待考试课程，通过后返回项目列表继续处理。
- 以课程、题干和选项内容识别试题，适应题目与选项顺序变化。
- 未知答案从尚未排除的选项中随机选择，优先使用已验证的内容。
- 核对本次提交与结果页反馈，匹配不明确时停止并输出诊断。
- 支持暂停、查看记录和清理队列，目前仅支持单选题。

## 安装与使用

安装脚本猫后，从[脚本发布页](https://scriptcat.org/zh-CN/script-show-page/8630)安装脚本。登录华医网，进入目标项目的课程列表，点击助手面板上的开始按钮。

主脚本：[`huayi-exam-helper.user.js`](./huayi-exam-helper.user.js)。当前版本为 2.3.9。题库和队列存储在浏览器本地，不随仓库发布。
